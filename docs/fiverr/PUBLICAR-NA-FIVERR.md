## Descrição pronta para copiar

Criei este portfólio pessoal para apresentar minha experiência, destacar projetos e facilitar o contato de potenciais clientes. A proposta foi organizar o conteúdo em uma página clara, responsiva e fácil de navegar.

A interface reúne apresentação, projetos, trajetória profissional, habilidades, currículo para download e formulário de contato com integração opcional ao EmailJS. O visitante pode alternar entre português e inglês e escolher os temas claro e escuro, com suas preferências salvas no navegador.

Entre os desafios estavam manter uma boa experiência no celular, organizar conteúdos de diferentes tamanhos e tornar os controles consistentes. Trabalhei na navegação por seções, no menu móvel e na adaptação dos componentes para diferentes telas.

O projeto utiliza React, TypeScript e Tailwind CSS, com testes de navegação automatizados em Playwright e verificações no GitHub Actions. A base inicial foi criada com auxílio do Lovable e recebeu personalizações e melhorias.

Este trabalho demonstra o serviço que ofereço: criação e personalização de portfólios profissionais para apresentar serviços, trabalhos e informações de contato com uma identidade visual alinhada ao cliente.
