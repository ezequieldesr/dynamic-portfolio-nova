# Roteiro de apresentação

Objetivo: mostrar o serviço de criação de portfólios para profissionais e freelancers.

1. Apresentação: abrir a página e destacar identidade, chamada principal e ações de contato.
2. Projetos: navegar pelos trabalhos e seus links, sem abrir sites externos durante a gravação.
3. Aparência: alternar para o tema escuro e depois para inglês; retornar ao português.
4. Perfil: mostrar experiência, habilidades e opção de baixar o currículo.
5. Contato: preencher dados fictícios, mostrar os campos e o contato alternativo, sem enviar e-mail real.
6. Celular: mostrar o menu responsivo e navegar até Projetos.

`npm run build` e `npm run demo:record` recriam as imagens e o vídeo WebM em docs/demo.
O script inicia um preview local próprio e bloqueia requisições ao EmailJS.
Para gerar MP4 e os cinco anexos da Fiverr: `npm run demo:export` (requer ffmpeg no PATH,
ou variável FFMPEG_PATH com caminho do executável).
O vídeo é uma gravação da interface real; não representa teste de entrega de mensagens.
